    Sequential vs concurrent

    Press "Compare" to run all tasks twice and measure the time.

    Sequential: each await task.run() waits for the previous task, so the total time is the sum of all task times. Concurrent: Promise.allSettled starts every task at once and the timers wait in parallel, so the total time is about the slowest single task.
